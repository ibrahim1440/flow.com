# Finance — visual decisions (review package, 2026-09-26)

Straightforward discrepancies were fixed in the application to match the agreed Figma frames
(FIGMA_PARITY.md §5). This sheet covers what remains. Nothing here is marked approved, and no
frame has been redrawn on the assumption that a recommendation will be accepted.

Crops: Figma = the named node exported from page "15 — Finance · Cash & Budget"; app = the same
card from the running build on the local fixture (`tests/finance/visual/decision-crops.mjs`).
"Changes" says what accepting the recommendation would change: **appearance** (how it looks),
**workflow** (what a user can do or must do), **permissions** (who may do it).
